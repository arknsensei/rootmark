# index — ajan notları
Sorumluluk: sözcüksel (tantivy), vektör deposu + kesin arama, embedder trait + ONNX varsayılan, hibrit RRF, kontrol noktasına göre sorgu, sıcak katman (docs/PACKAGES.md `index`; GOAL P1-C).
Bağımlılık yönü: core ← index ← server ← clients; `index` yalnız `core`'a bağlıdır. Ters yön yasak (`scripts/check_deps.sh`). `rootmark index …`/`rootmark search …` mantığı `index/src/cli.rs`'tedir; P1-D/D0'dan beri `server`'ın `rootmark` ikilisi onu doğrudan çağırır, `rootmark-index` ikilisi aynı modülün bağımsız girişidir (`models verify`, dondurulmuş betikler).
Dil ve araçlar: Rust 1.92.0; `tantivy =0.26.2`, `ort =2.0.0-rc.13` (CPU, `intra_threads=1`), `tokenizers =0.23.2`, `ndarray =0.17.2`. Model dosyaları `models/` (git dışı), `scripts/fetch_model.sh` + `make models` (`models/MANIFEST.json`, blake3).
Dondurulmuş yüzeyler: spec §9 davranışı (kesin arama, eşitlikte `(doc_path, chunk_id)`, aynı checkpoint + sorgu → aynı sıralama; P1-C.1: canonical-yalnız istatistik, ayrı proposal geçişi K-C1.3, boş sorgu `Err` K-C1.5, sorgu indeks dizinine yazmaz K-C1.4, manifest `lexical.*` K-C1.1); `embedder_id` kuralı; uyumluluk fixture'ları (`spec/fixtures/C3-*`, C7'den itibaren).
Test komutları: `cargo test -p rootmark-index --release`; `make models`; `make conformance`.
Bu pakette yapılmayacaklar: ANN (HNSW vb.); graf/varlık/reranker sıralaması (K3); birden fazla embedder; GPU; çok iş parçacıklı embedding ya da indeks yazımı; markdown dosyasına yazma; MCP/HTTP (P1-D).
