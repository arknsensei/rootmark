## Kusur / risk notları (engelleyici değil)
1. **Varsayılanın ortam değişkenine bağlı olması.** Dondurulmuş v2 kodu `Vault(...)`'u sürüm vermeden çağırdığı için v2 davranışı yalnız `MDK_MATCHER=v2` ile korunuyor. `make` hedefleri bunu yapıyor; ancak `eval/*` modülleri `make` dışında doğrudan çağrılırsa sessizce V3 ile koşar (farklı `matcher_version`, farklı hash). Önceki v2 koşturmalarının yeniden üretimi (T19 tipi doğrulama, `scripts/verify.sh`) bu ortam değişkenine bağımlı hale geldi; `scripts/verify.sh` kontrol edildi: veri, dondurma ve değerlendirme adımlarını `make` hedefleri (`PY2`) üzerinden çağırıyor; yalnız `eval.runinfo` ve `eval.compare_runs` doğrudan `uv run python` ile koşuyor (bunlar ingest yapmıyor gibi görünüyor; v3 görevlerinde yeni koşturucular eklenirken matcher'ın açıkça verilmesi önerilir). Varsayım ASSUMPTIONS'ta `[H4]` etiketiyle kayıtlı.
2. **`make test-py` `MDK_MATCHER` olmadan koşuyor.** Eski v2 Python testleri artık V3 varsayılanıyla çalışıyor (geçiyorlar). V2 semantiğini kodlayan bir Python testi varsa, bundan sonra V2 yolunu değil V3 yolunu sınıyor olabilir. Rust tarafında V2 kapsamı açıkça korunmuş.
3. **mini_vault V3 hash farkı yalnız `matcher_version` dizgesinden geliyor.** mini_vault tek geçişte ingest edildiği için tüm olaylar `BlockCreated`; V3/V2 farkı eşleyici mantığını değil etiket alanını yansıtıyor. Ölçüt sözcük olarak sağlanıyor; eşleyici farkı lineage_v3 testleri ve yukarıdaki D1 çok-sürüm sınamasıyla ayrıca gösterildi.
4. **K4'ün adım 5 (artık bölme) sonuçlarına da uygulanması** SPEC'te "adım 5 değişmez" ifadesinin yorumudur; ASSUMPTIONS'ta `[H1]` ile kayıtlı. Tutarlı (K4 tüm `BlockSplit` olaylarına uygulanıyor) ve makul.
5. V3 `BlockMerged` olayları ek `meta.residual` anahtarı taşıyor (V2'de yok). Şemaya ekleme; V2 çıktısını etkilemiyor.
6. `MDK_MATCHER=""` (boş) `unknown matcher version ""` hatası veriyor — fail-fast açısından kabul edilebilir.
7. `Vault::params` alanının türü `MatchParams` → `Option<MatchParams>` oldu (genel API değişikliği); depoda başka kullanıcısı yok, derleme temiz.
