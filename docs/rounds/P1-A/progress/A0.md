# A0 — Kaynak teyidi ve etiket

BAŞLADI

Plan:
1. Prototip deposunda `v3-final` etiketinin varlığını ve sha'sını teyit et (yoksa HEAD'e at).
2. `git subtree add --prefix=prototype <BSv2> v3-final` ile prototip geçmişini içe al (squash yok → orijinal commit sha'ları korunur).
3. Prototipin `v2-final` / `v3-final` etiketlerini bu depoda aynı commit'lere işaret edecek şekilde oluştur (dondurulmuş testler `git show v2-final:...` kullanıyor).
4. `progress/SOURCE.md`: prototip sha'ları, v2/v3 RUN manifest hash'leri, veri MANIFEST hash'leri.
5. Gözden geçirici alt-ajan → `A0.review.md`; commit `P1-A/A0: ...`.

## Kabul
- [x] `git log` prototip geçmişini içeriyor (subtree, squash yok): `git log --oneline v3-final | wc -l` = prototipteki commit sayısı; `git log -- prototype` birleştirme commit'ini gösteriyor; prototip sha'ları (`71c244e`, `5c53be4`) bu depoda çözülüyor.
- [x] Sabit sha `SOURCE.md`'de kayıtlı (`v3-final` = `71c244e5…`, `v2-final` = `5c53be42…`), v2/v3 RUN manifest hash'leri ve veri MANIFEST hash'leri kayıtlı.

Not: etiketler `git clone` ile taşınır (klonda `refs/tags/*` gelir); doğrulayıcı `git archive v3-final core` ile v3-final çekirdeğine erişebilir.
