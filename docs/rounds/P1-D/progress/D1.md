# D1 — MCP sunucusu: yazmayan araçlar

BAŞLADI

Plan:
1. `server/src/tools.rs`: taşımadan bağımsız araç çekirdeği (`Kernel::call(name, args, consumer)` → JSON ya da `Err`), araç tanımları (ad, spec terimleriyle `description`, JSON Schema `inputSchema`, `additionalProperties: false`). D1: `status`, `history`, `blame`, `checkpoints`, `trace`; çıktılar CLI'nin aynı komutlarıyla aynı JSON.
2. `server/src/mcp.rs`: `rmcp` `ServerHandler` (elle `list_tools`/`call_tool`), stdio; tüketici kimliği `initialize` el sıkışmasındaki `clientInfo` (`<name>/<version>`); el sıkışması olmayan protokol sürümleri sunulmaz.
3. `mdk serve --vault <path> --mcp stdio`.
4. `server/examples/mcp_client.rs`: kilit adımlı stdio JSON-RPC sürücüsü (istek yaz → aynı `id`'li yanıtı bekle); `scripts/mcp_e2e.sh` iskeleti (5 araç, iki koşturma, karşılaştırma).
5. `scripts/mcp_inspector.sh`: resmi MCP Inspector (`@modelcontextprotocol/inspector@2.9.0 --cli`) ile `tools/list` + her araç için `tools/call`; şemalar `server/tests/mcp_schemas.rs` ile JSON Schema meta-şemasına karşı doğrulanır.

## Kabul
- [x] **Inspector 5/5 şema:** `bash scripts/mcp_inspector.sh <dir>` → `mcp_inspector: schemas 5/5 valid, Inspector calls 5/5` (çıkış 0). `tools_list.json` resmi Inspector'ın (`@modelcontextprotocol/inspector@2.9.0`, 2026-09-30) `tools/list` çıktısı; `mcp_schemas` testi her `inputSchema`'yı JSON Schema 2020-12 meta-şemasına karşı doğrular, derler, `type: object` + `additionalProperties: false` + `required ⊆ properties` + her özelliğin açıklaması + bilinmeyen argümanın reddi, ve listenin sunucunun araçları/şemaları/açıklamalarıyla aynı olması. Her araç Inspector üzerinden bir kez çağrıldı (`isError: false`).
- [x] **Kasıtlı şema bozma:** `history.inputSchema.properties.lineage_id = 5` olan liste → `schemas 4/5 valid`, çıkış 1.
- [x] **e2e 5/5:** `bash scripts/mcp_e2e.sh <dir>` → `tools 5/5, handshake true, runs equal true`; 21 denetim (her araç için geçerli çağrı + içerik + en az bir kasıtlı hata: bilinmeyen argüman, bilinmeyen soy, t0'da olmayan doküman, eksik `doc_path`, negatif `since_seq` → hepsi `isError: true`, `error: …` metni).
- [x] **Deterministik:** iki koşturmanın `transcript.jsonl`'leri ve vault `events.jsonl`/`traces.jsonl` dosyaları `cmp` ile eşit (vault yolu göreli `vault`, transkriptte zaman damgası/token yok).
- [x] **Tüketici kimliği:** `initialize` `clientInfo` → `<name>/<version>` (`mcp::consumer_of`); el sıkışmasız protokol sürümleri (2026-07-28) sunulmaz (`supported_protocol_versions` ≤ 2025-11-25). İz yazan araçlar D3'te kimliksiz istemciyi reddeder (`Kernel::call(…, consumer: Option<&str>)`).
- [x] Yazmayan araçların çıktısı CLI ikiziyle aynı JSON (`history`, `blame`, `checkpoint list` → `checkpoints`, `trace list` → `trace`); `history` bilinmeyen soyda CLI gibi boş liste değil hata döner (sessiz başarısızlık yok).
- [x] `cargo fmt --check`, `clippy -D warnings`, `check_deps.sh` temiz; `cargo test -p mdkernel-server --release` geçti.

Yeni dosyalar: `server/src/{lib,tools,mcp}.rs`, `server/examples/mcp_client.rs` (yalnız test sürücüsü), `server/tests/mcp_schemas.rs`, `scripts/{mcp_e2e,mcp_inspector}.sh`; `server/src/bin/mdk.rs` (`serve`), `server/Cargo.toml` (`jsonschema =0.58.3` dev).
