3. D1.md'deki "`history` bilinmeyen soyda CLI gibi boş liste değil hata döner" ifadesi yanlış. `mdk history <vault> zz` de `error: no event names lineage zz` ile çıkış 1 veriyor; hatayı çekirdekteki `Vault::history` üretiyor.
