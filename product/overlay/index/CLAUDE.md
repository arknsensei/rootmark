# index — agent notes
Responsibility: lexical index (tantivy), vector store and exact search, the embedder trait and the default MiniLM (ONNX weights, a fixed-order Rust forward pass `detbert`), hybrid RRF, queries at a checkpoint, the hot layer.
Dependency direction: core ← index ← server ← clients; `index` depends on `core` only. `rootmark index …` / `rootmark search …` live in `index/src/cli.rs`; the `rootmark` binary of `server` calls them directly.
Language and tools: Rust 1.92.0; `tantivy =0.26.2`, `tokenizers =0.23.2`. Embedding in `src/detbert.rs`: the weights of `model.onnx` are read by its own protobuf reader, every component in a fixed order (FMA, no platform `libm`), no threads — the vector bytes are the same on every processor. A change to the numeric path changes the `embed::NUMERICS` label and the golden bytes of `index/tests/p2v1_embed.rs` are recorded again. Model files live in `models/` (not in git): `scripts/fetch_model.sh`, `make models` (`models/MANIFEST.json`, blake3).
Frozen surfaces: the search behaviour of spec §9 (exact search, ties broken by `(doc_path, chunk_id)`, the same checkpoint and query give the same ranking; statistics over canonical blocks only, a separate proposal pass; an empty query is an error; a query never writes into the index directory); the `embedder_id` rule (`<name>/<blake3[:8]>+<NUMERICS>`); the conformance fixtures `spec/fixtures/C3-*`.
Test commands: `cargo test -p rootmark-index --release`; `make models`; `make conformance`.
Options: `[index] tokenizer` (`mdk_lower_alnum` default, `uni_fold_tr`) and `[index] embedder` (`minilm-l6-v2` default, `multilingual-minilm-l12-v2`; `make models-multilingual`) per vault; one embedder and one lexical variant per index (manifest).
Not in this package: ANN (HNSW etc.); graph/entity/reranker ranking; more than one embedder in an index; GPU; multi-threaded embedding or index writes; writing Markdown files; MCP/HTTP.
