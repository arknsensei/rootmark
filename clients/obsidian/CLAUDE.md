# clients/obsidian — ajan notları
Sorumluluk: minimal Obsidian istemcisi (docs/PACKAGES.md `clients/obsidian`, GOAL P1-E): blame paneli, proposal görünümü + Promote/Demote, arama, checkpoint, trace görüntüleyici; ürün sahnesinin insan tarafı.
Bağımlılık yönü: core ← index ← server ← clients. İstemci çekirdeğe **yalnız** `docs/CLIENT_CONTRACT.md` üzerinden bağlanır: HTTP `POST /v1/<araç>` / `GET /v1/status`, `Authorization: Bearer <.rootmark/server.token>`, `X-Consumer`. `core/`, `index/`, `server/`, `bindings/`, `research/` içe aktarılmaz; kaynakta sözleşme dışı `/v1/<x>` yolu yazılmaz (`scripts/check_deps.sh`).
Dil ve araçlar: TypeScript (`tsc --strict`), `esbuild` (bundle `main.js`, `obsidian` ve CodeMirror harici), `eslint` (typescript-eslint strict), `vitest`. Bütün paketler dev-dependency, tam sürüme sabit ve ≥ 14 gün önce yayımlanmış; **çalışma zamanı bağımlılığı yok** (Obsidian API uygulamadan gelir).
Dondurulmuş yüzeyler: yok (sözleşme `docs/CLIENT_CONTRACT.md`'dedir ve sunucu tarafında denetlenir).
Test komutları: `npm ci && npm test` (`make test-ts`), `npm run lint` (`make lint-ts`), `npm run build`.
Bu pakette yapılmayacaklar: md dosyasına yazma (`vault.modify`, `vault.create`, `vault.append`, `adapter.write`, `adapter.append` …; tek yazma yolu HTTP araçları); `rootmark serve`'i başlatma (sunucu yoksa pasif durum); `policy.toml` ya da token yazma; sözleşmede olmayan bir davranışa güvenme; çok vault; uzak sunucu; çalışma zamanı bağımlılığı.
